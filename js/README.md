# Forge — Responsive Multi-Page Landing Website

A responsive 4-page landing website built with vanilla HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home (hero, marquee, feature preview, testimonial preview, CTA)
- `features.html` — Full feature grid + 3-step process
- `testimonials.html` — Customer stories + stats band
- `contact.html` — Contact form with validation + FAQ

## Tech
- HTML5 (semantic, accessible)
- CSS3 (custom properties, Grid, Flexbox, clamp)
- Vanilla JavaScript (no frameworks)

## Features
- Sticky navbar with mobile hamburger menu
- Active nav link detection per page
- Scroll reveal animations (IntersectionObserver)
- Contact form validation (name, email, message)
- Fully responsive (desktop / tablet / mobile)
- Accessible (skip link, ARIA, reduced-motion support)

## Color Theme
