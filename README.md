# Forge — Responsive Multi-Page Landing Website

A responsive 4-page landing website built with vanilla HTML, CSS, and JavaScript.

## Live Demo
https://ahmadali-01.github.io/forge-landing/

## Pages
- `index.html` — Home
- `features.html` — Full feature grid + steps
- `testimonials.html` — Customer stories + stats
- `contact.html` — Contact form + FAQ

## Tech
HTML5, CSS3, vanilla JavaScript (no frameworks).

## Features
- Sticky navbar with mobile hamburger menu
- Active nav link per page
- Scroll reveal animations
- Contact form validation
- Fully responsive
- Accessible (skip link, ARIA, reduced-motion)

## Color Theme
Forest green + electric lime. No blue, no purple.
